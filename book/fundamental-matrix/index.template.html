Start with Picard iteration. Build one matrix. Reuse it for every initial state and every forcing term.

Picard iteration begins before linearity enters. Work through two nonlinear equations, then see how linearity turns the same repeated integration into a reusable matrix—whether the coefficients are constant or variable, with or without forcing.

The examples at the right follow the text. Change the number of iterations and watch a solution emerge.

01 / The starting point

Integrate. Substitute. Repeat.

Begin with an initial-value problem, not with a proposed answer:

\[x'(t)=f(t,x(t)),\qquad x(t_0)=x_0.\]

Its integral form suggests its own approximation scheme:

\[\begin{aligned} x^{[0]}(t)&=x_0,\\ x^{[n+1]}(t)&=x_0+\int_{t_0}^{t}f(s,x^{[n]}(s))\,ds. \end{aligned}\]

Each step uses the previous approximate path to compute a better one. This is Picard iteration. For a continuous right-hand side that is locally Lipschitz in the state variable, with a locally uniform constant in time, the iteration works on a sufficiently small interval around the initial time.[1]

The exponential is an output

For \(y'=y\), \(y(0)=1\), start with the constant function \(1\):

\[\begin{aligned} y^{[0]}(t)&=1,\\ y^{[1]}(t)&=1+t,\\ y^{[2]}(t)&=1+t+\frac{t^2}{2},\\ y^{[n]}(t)&=\sum_{k=0}^{n}\frac{t^k}{k!}. \end{aligned}\]

The exponential series appears without being guessed. First try two nonlinear equations. Then repeat the construction with matrices, and with a forcing term already present.

Try it: increase \(N\) in the notebook. The solid curve is the actual \(N\)-th Picard iterate, not a numerical time-stepping solution.

02 / What linearity gives us

Compute every initial state at once.

Now take a finite-dimensional linear system

\[x'(t)=A(t)x(t)+b(t),\qquad x(t_0)=x_0.\]

Assume that the matrix \(A\) and vector \(b\) are continuous on an interval \(I\). Its iteration is still just

\[x^{[n+1]}(t)=x_0+\int_{t_0}^{t}\bigl(A(s)x^{[n]}(s)+b(s)\bigr)\,ds.\]

First collect the terms multiplying the initial vector. They do not depend on the forcing. For a starting time \(s\), define

\[P_0(t,s)=I_d,\qquad P_{n+1}(t,s)=\int_s^t A(u)P_n(u,s)\,du.\]

The partial sums are exactly the matrix versions of the Picard iterates:

\[U_N(t,s)=\sum_{n=0}^{N}P_n(t,s).\]

Writing out two terms makes the order visible:

\[U(t,s)=I_d+\int_s^t A(u)\,du+\int_s^t\int_s^u A(u)A(v)\,dv\,du+\cdots.\]

For forward time, the later matrix stands on the left. Matrix multiplication cannot usually be reordered. This ordered integral expansion is called the Peano–Baker series.[2] The object it constructs is the fundamental matrix, normalized at \(s\):

\[\partial_t U(t,s)=A(t)U(t,s),\qquad U(s,s)=I_d.\]

Its \(j\)-th column is the solution starting at the \(j\)-th coordinate vector. Multiplying by \(x_0\) therefore gives the homogeneous solution for any initial vector.

When does an ordinary matrix exponential suffice?

If \(A\) is constant, then \(P_n(t,s)=A^n(t-s)^n/n!\), so \(U(t,s)=e^{(t-s)A}\). More generally, if \(A(u)A(v)=A(v)A(u)\) for every pair of times, the ordered simplex is one of \(n!\) interchangeable parts of the integration cube. Consequently,

\[P_n(t,s)=\frac{1}{n!}\left(\int_s^t A(u)\,du\right)^n,\qquad U(t,s)=\exp\!\left(\int_s^t A(u)\,du\right).\]

The scalar case always commutes. The noncommuting example below shows why the condition matters for matrices.

Two times, not one elapsed time. The notation \(U(t,s)\) remembers both the arrival time and the departure time. With variable coefficients, it generally cannot be replaced by \(U(t-s,0)\).

03 / Forcing is already in the iteration

Let each contribution travel forward.

A contribution \(b(s)\,ds\) enters at time \(s\). After that, it is transported by the same matrix \(U(t,s)\). Adding all these contributions gives

\[\int_{t_0}^{t}U(t,s)b(s)\,ds.\]

This is not a new ansatz. It is what the forcing terms in Picard iteration become when they are collected according to their time of entry.

See the regrouping directly

Write \((Kh)(t)=\int_{t_0}^{t}A(s)h(s)\,ds\) and \(q(t)=\int_{t_0}^{t}b(s)\,ds\). Regard \(x_0\) as a constant function. The exact finite iteration is

\[x^{[N]}=\sum_{k=0}^{N}K^k x_0+\sum_{k=0}^{N-1}K^kq.\]

The second sum is empty when \(N=0\). Reversing the order of integration on each finite simplex gives

\[(K^kq)(t)=\int_{t_0}^{t}P_k(t,s)b(s)\,ds.\]

Letting \(N\) grow produces the forcing integral above. The convergence estimate below justifies passing to the limit. Backward time follows with oriented integrals.

The main theorem

One formula for every linear initial-value problem.

Let \(A:I\to\mathbb R^{d\times d}\) and \(b:I\to\mathbb R^d\) be continuous on an interval, and let \(t_0\in I\). The series \(U=\sum_{n\ge0}P_n\) converges uniformly on compact time intervals. The unique solution is

\[\boxed{x(t)=U(t,t_0)x_0+\int_{t_0}^{t}U(t,s)b(s)\,ds.}\]

All of the dependence on the coefficients is in \(U\). The initial state and forcing can be changed without changing that matrix.

The formula is often presented under the name “variation of constants.” Here it is a consequence of repeated integration, not a separate solving technique.[1][2]

Even forcing can be put inside a matrix

Adjoin the constant coordinate \(1\):

\[z=\begin{pmatrix}x\\1\end{pmatrix},\qquad \widehat A(t)=\begin{pmatrix}A(t)&b(t)\\0&0\end{pmatrix},\qquad z'=\widehat A(t)z.\]

The very same matrix iteration now gives

\[\widehat U(t,s)=\begin{pmatrix}U(t,s)&\displaystyle\int_s^t U(t,r)b(r)\,dr\\0&1\end{pmatrix}.\]

This is also how the notebook is implemented. For each example it caches the polynomial terms of an augmented fundamental matrix. Changing the initial state, or scaling the fixed forcing profile, only changes the vector it multiplies.

Why it really is a fundamental matrix

Uniqueness gives the composition law and its inverse:

\[U(t,r)U(r,s)=U(t,s),\qquad U(t,s)^{-1}=U(s,t).\]

Thus the columns remain independent. If \(X(t)=U(t,t_0)\), the familiar one-time notation is recovered as \(U(t,s)=X(t)X(s)^{-1}\). The two-time construction does not require finding that inverse first.

04 / Worked example 1

A variable coefficient and a forcing term.

\[y'=2ty+2t,\qquad y(0)=a.\]

Here \(A(t)=2t\), so the recursion immediately gives

\[P_n(t,s)=\frac{(t^2-s^2)^n}{n!},\qquad U(t,s)=e^{t^2-s^2}.\]

The complete solution is therefore

\[\begin{aligned} y(t)&=a e^{t^2}+\int_0^t e^{t^2-s^2}\,2s\,ds\\ &=(a+1)e^{t^2}-1. \end{aligned}\]

The direct iterates make the same answer visible term by term:

\[y^{[N]}(t)=(a+1)\sum_{k=0}^{N}\frac{t^{2k}}{k!}-1.\]

No integrating factor had to be chosen. In the notebook, the forcing control replaces \(2t\) by \(\lambda\,2t\); the answer becomes \((a+\lambda)e^{t^2}-\lambda\).

05 / Worked example 2

The oscillator, including resonance.

A second-order equation is a first-order system with two coordinates:

\[y''+y=g(t),\qquad x=\begin{pmatrix}y\\y'\end{pmatrix},\quad A=\begin{pmatrix}0&1\\-1&0\end{pmatrix},\quad b=\begin{pmatrix}0\\g\end{pmatrix}.\]

Now \(A^2=-I_2\). Repeated integration gives \(P_n(t,s)=A^n(t-s)^n/n!\), so the even and odd terms collect into

\[U(t,s)=\begin{pmatrix}\cos(t-s)&\sin(t-s)\\-\sin(t-s)&\cos(t-s)\end{pmatrix}.\]

With \(y(0)=a\) and \(y'(0)=c\), the general formula reads

\[y(t)=a\cos t+c\sin t+\int_0^t\sin(t-s)g(s)\,ds.\]

For zero initial data, two very different-looking cases use exactly the same integral:

\[\begin{aligned} g(t)=1&\quad\Longrightarrow\quad y(t)=1-\cos t,\\ g(t)=\cos t&\quad\Longrightarrow\quad y(t)=\frac{t}{2}\sin t. \end{aligned}\]

The second is the resonant response. There is no exceptional rule about multiplying a guessed particular solution by \(t\): that factor comes out of the integral.

The notebook uses constant forcing \(g(t)=\lambda\), so that every finite iterate remains an exactly computed rational polynomial.

06 / Worked example 3

When the order matters—and the series stops.

Take a genuinely noncommuting family:

\[A(t)=\begin{pmatrix}0&1&0\\0&0&t\\0&0&0\end{pmatrix}.\]

In fact \([A(u),A(v)]=(v-u)E_{13}\), where \(E_{13}\) has a single \(1\) in position \((1,3)\). Every product of three of these matrices vanishes. Thus only two integrations survive:

\[P_1(t,0)=\begin{pmatrix}0&t&0\\0&0&t^2/2\\0&0&0\end{pmatrix},\qquad P_2(t,0)=\begin{pmatrix}0&0&t^3/6\\0&0&0\\0&0&0\end{pmatrix}.\] \[U(t,0)=\begin{pmatrix}1&t&t^3/6\\0&1&t^2/2\\0&0&1\end{pmatrix}.\]

Contrast this with the tempting but incorrect replacement:

\[\exp\!\left(\int_0^t A(s)\,ds\right)=\begin{pmatrix}1&t&t^3/4\\0&1&t^2/2\\0&0&1\end{pmatrix}.\]

The \((1,3)\)-entry is wrong. Ordered integration is not notation for an ordinary exponential.

The forcing still needs no new method

For \(x(0)=0\) and \(b(t)=(0,0,1)^{\mathsf T}\), the same iteration gives

\[x^{[1]}=\begin{pmatrix}0\\0\\t\end{pmatrix},\qquad x^{[2]}=\begin{pmatrix}0\\t^3/3\\t\end{pmatrix},\qquad x^{[3]}=\begin{pmatrix}t^4/12\\t^3/3\\t\end{pmatrix}.\]

The third iterate is already the exact solution. In the homogeneous notebook example, \(N=2\) is enough; turning on forcing can require one more iteration.

07 / Worked example 4

An equation that makes its own special functions.

For \(y''=ty\), the system matrix is

\[A(t)=\begin{pmatrix}0&1\\t&0\end{pmatrix}.\]

Its first two ordered terms are

\[P_1(t,0)=\begin{pmatrix}0&t\\t^2/2&0\end{pmatrix},\qquad P_2(t,0)=\begin{pmatrix}t^3/6&0\\0&t^3/3\end{pmatrix}.\]

The higher terms build two normalized solutions:

\[\begin{aligned} u(t)&=1+\frac{t^3}{6}+\frac{t^6}{180}+\frac{t^9}{12960}+\cdots,\\ v(t)&=t+\frac{t^4}{12}+\frac{t^7}{504}+\frac{t^{10}}{45360}+\cdots. \end{aligned}\]

They satisfy \((u(0),u'(0))=(1,0)\) and \((v(0),v'(0))=(0,1)\). Thus

\[U(t,0)=\begin{pmatrix}u(t)&v(t)\\u'(t)&v'(t)\end{pmatrix}.\]

This is Airy’s equation.[3] The usual \(\operatorname{Ai}\) and \(\operatorname{Bi}\) are another choice of basis; they need not be known in advance. The iteration constructs the functions that the equation needs.

Add any continuous forcing

Since \((uv'-u'v)'=u(tv)-(tu)v=0\), the Wronskian is \(1\). The same formula for \(y''=ty+g(t)\) now becomes

\[y(t)=a\,u(t)+c\,v(t)+\int_0^t\bigl(v(t)u(s)-u(t)v(s)\bigr)g(s)\,ds.\]

For \(g=1\) and zero initial data, the iteration gives a third explicitly convergent series:

\[w(t)=\frac{t^2}{2}+\frac{t^5}{40}+\frac{t^8}{2240}+\frac{t^{11}}{246400}+\cdots.\]

Indeed, substituting \(y=\sum c_nt^n\) into \(y''=ty+1\) gives \(c_2=1/2\) and

\[c_{n+2}=\frac{c_{n-1}}{(n+1)(n+2)}\quad(n\ge1).\]

Changing the initial coefficients produces \(u\) and \(v\) in the homogeneous case. “Solving” here means constructing and evaluating a convergent answer, not necessarily expressing it with a fixed list of elementary functions.

08 / The scope of “every linear ODE”

Higher order only changes the matrix.

For an equation already in normal form,

\[y^{(m)}+a_{m-1}(t)y^{(m-1)}+\cdots+a_0(t)y=g(t),\]

set \(x=(y,y',\ldots,y^{(m-1)})^{\mathsf T}\). Then

\[A(t)=\begin{pmatrix}0&1&0&\cdots&0\\0&0&1&\cdots&0\\\vdots&\vdots&\vdots&\ddots&\vdots\\0&0&0&\cdots&1\\-a_0&-a_1&-a_2&\cdots&-a_{m-1}\end{pmatrix},\qquad b(t)=\begin{pmatrix}0\\0\\\vdots\\0\\g(t)\end{pmatrix}.\]

Nothing else changes. For a non-unit leading coefficient, first divide by it on an interval where it does not vanish. The theorem does not promise continuation through a singular coefficient, nor does it assert that arbitrary boundary conditions are consistent.

09 / Why the construction works

The factorial does the work.

Choose a submultiplicative matrix norm. If \(\|A(t)\|\le M\) throughout an interval of length \(L\), repeated integration gives

\[\|P_n(t,s)\|\le\frac{(M|t-s|)^n}{n!}\le\frac{(ML)^n}{n!}.\]

Each new integration contributes an extra denominator. The series therefore converges uniformly on the interval, with

\[\|U(t,s)-U_N(t,s)\|\le\sum_{n=N+1}^{\infty}\frac{(ML)^n}{n!}.\]

There is no requirement that \(ML<1\). This is the advantage of keeping the iterated integral estimate, rather than demanding that one Picard step be a contraction.[2]

A finite, rational tail bound

Put \(z=ML\). Whenever \(N+2>z\), successive omitted terms have ratio at most \(z/(N+2)\), so

\[\sum_{n=N+1}^{\infty}\frac{z^n}{n!}\le\frac{z^{N+1}}{(N+1)!}\,\frac{1}{1-z/(N+2)}.\]

For smaller \(N\), add finitely many omitted terms until this ratio bound applies. Rational \(M,L\) give a rational bound without needing to evaluate an exponential.

Existence and uniqueness from the same estimate

Uniform convergence permits integration of the sum in the recursive identity, giving \(U(t,s)=I_d+\int_s^t A(r)U(r,s)\,dr\). The fundamental theorem of calculus then gives \(\partial_tU=AU\).

If two solutions have the same initial value, their difference \(d\) satisfies \(d(t)=\int_{t_0}^t A(s)d(s)\,ds\). On a compact interval let \(D=\sup\|d\|\). Iterating this equality gives, for every \(n\),

\[\|d(t)\|\le D\frac{(ML)^n}{n!}.\]

The right side tends to zero, so \(d=0\). For the forced formula, differentiating the integral gives \(b(t)+A(t)\int_{t_0}^tU(t,s)b(s)\,ds\), and its initial value is zero. This finishes the proof for the full system.

The bound used in the notebook

On \([0,T]\), let \(\|A(t)\|_\infty\le M\), \(\|b(t)\|_\infty\le B\), and \(\|x_0\|_\infty=R\). If \(M>0\), the full Picard iterate satisfies

\[\sup_{0\le t\le T}\|x(t)-x^{[N]}(t)\|_\infty\le\left(R+\frac{B}{M}\right)\sum_{n=N+1}^{\infty}\frac{(MT)^n}{n!}.\]

This follows by bounding successive differences, starting with \(\|x^{[1]}(t)-x^{[0]}(t)\|\le(MR+B)t\). The displayed bound is rounded upward. For a terminating series, it bounds the actual remaining polynomial directly. If the exact polynomial residual is zero, it reports zero truncation error.

If \(M=0\), the first iterate is exact and the zeroth has error at most \(BT\). These are mathematical truncation bounds; they do not enclose the floating-point conversion and rendering used to draw the curves.

A solution need not be an elementary expression. The integral series defines the solution even when its terms have no elementary antiderivatives. In the polynomial examples, every finite iterate can be calculated explicitly. The convergence estimates explain why those finite expressions approach the required solution.

Picard iteration is the common starting point. For linear equations, it produces one fundamental matrix: constant coefficients, variable coefficients and forcing become instances of the same construction.

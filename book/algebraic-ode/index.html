Algebraic solutions, built on computable numbers and certified finite differences.

This subproject uses the book’s rational interval algorithms and represented complex values. It has no Mathlib dependency. The general classification remains open.

Euler–Fuchs: a coefficient obstruction

x y′ = r y   ⟹   (k − r)ck = 0

For a finite rational polynomial y = Σ ckxk, the coefficient equations hold exactly when every nonzero coefficient has degree k = r. We prove that this certificate implies the evaluated differential identity using the existing polynomial derivative. A nonzero polynomial solution therefore forces r to be a nonnegative integer.

For yn = xm, we also check the algebraic elimination yielding nxy′ = my, assuming the differentiated relation, y ≠ 0, and n ≠ 0. This does not construct a branch or prove implicit differentiation.

Painlevé: equations and algebraic seeds

PI: y″ = 6y² + x
PII(α): y″ = 2y³ + xy + α

In the DLMF convention, PI has no rational constant solution. For PII, the only rational affine solution is y = 0 at α = 0.

The simple-pole candidate y = c/x satisfies PII for every nonzero rational x exactly when α = −c and c ∈ {0, 1, −1}.

What the computation certifies

A polynomial residual evaluated on valid computable complex inputs is valid and respects overlap equivalence. At exact rational inputs its actual interval runtime agrees with the rational result at every stage.

The generic residual interface does not assert that supplied jets are derivatives. The concrete Painleve.AlgebraicSolutionOn package requires those certificates. Every defining algebraic relation includes a nonzero witness, excluding the vacuous equation 0 = 0.

Existing formalizations to compare

A public web and GitHub search on 22 September 2026 did not locate an inspectable formalization of the Fuchs–Painlevé algebraic-solution classification. This is a bounded search result, not a claim of nonexistence.

  • CoRN / MathClasses: the Picard algorithm in Coq, by Makarov and Spitters. Constructive exact reals and a correctness-certified Picard development; the closest foundation-level comparison. Public ODE source.
  • Isabelle AFP: Ordinary Differential Equations. Existing existence, uniqueness, flow and verified numerical work, using a different analysis foundation.
  • Solving Differential Equations in Rocq. A 2026 proposal explicitly targeting Painlevé I among numerical examples. It is not evidence of a completed implementation or algebraic classification.
  • Mason–Stothers and its corollaries in Lean 4. An adjacent comparison for polynomial derivative, degree and nonexistence arguments.

The remaining programme

Next are normalized rational differential algebra, certified algebraic branches and Puiseux charts, regular-singular Fuchs theory, and a separate first-order Fuchs criterion development. For PII, the next targets are pole and degree obstructions, Bäcklund transformations and rational-solution classification.

General algebraic-solution classification, PI algebraic nonexistence, monodromy, and PIII–PVI are not proved in this milestone. Formal residuals and conditional jet identities are kept distinct from analytic solutions.

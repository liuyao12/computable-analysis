A common elementary starting point

Every integration theory here should support piecewise-constant functions along continuous piecewise-linear paths. On a common subdivision of the path and the function's jumps, the elementary value is

\[I_\gamma(f)=\sum_i c_i\bigl(z_{i+1}-z_i\bigr).\]

Splitting a piece with the same constant leaves the value unchanged by finite cancellation. Reversing the path changes its sign. Values at the finitely many breakpoints do not affect it. The constants and vertices may be represented complex numbers; rational inputs give exact finite examples.

The constants describe the function along the path pieces. On a path that revisits a point, a single-valued function on the plane must give compatible values on repeated visits. More general values along a parametrized path should be described as such.

From an elementary computation to another function

For a straight piece with displacement \(\Delta z_i\), a proved whole-piece estimate \(|f(z)-c_i|\le\varepsilon_i\) suggests the comparison

\[\left|\int_\gamma f(z)\,dz-\sum_i c_i\Delta z_i\right|\le\sum_i\varepsilon_i|\Delta z_i|.\]

The integral's comparison law must be justified before using this as an error certificate. Rational bounds on displacement lengths are enough. Shrinking the right-hand side can prove agreement and uniqueness; it is one sufficient route, not a restriction that every possible integrand must satisfy.

The function-specific skills explain how to get those bounds or use another justified construction: pole separation, monotonicity, Taylor remainders, branch charts, and endpoint allowances. They distinguish proved results from work still needed.

A checked construction · Lean 4

Zeta for real exponents

The defining series now gives a certified computation for every represented real s > 1, using finite rational boxes.

Beyond integer inputs

The earlier zeta evaluator accepted integer exponents. The new function accepts any valid interval algorithm whose output eventually lies strictly above 1. It finds a separating box, selects a rational interval on which the estimates hold, and refines the input as far as each output precision requires.

Equivalent input algorithms give equivalent answers, even if they select different intervals. At every integer n ≥ 2, the result agrees with the earlier Dirichlet-series computation. In particular, the target ζ(3) in the Apéry development is unchanged.

A power series inside a Dirichlet series

For a rational exponent s, start with the generalized binomial coefficients:

c₀(s) = 1,   cₖ₊₁(s) = cₖ(s)(k + 2 − s)/(k + 1).

f(z) = Σ cₖ(s)zᵏ = (1 − z)s−2.

The checked recurrence is precisely the coefficient equation for (1 − z)f′ = (2 − s)f with f(0) = 1, and it has a unique formal coefficient solution. Substituting z = 1 − 1/n gives the binomial computation of n−s.

Both infinite sums are handled through finite rectangles. With n starting at 1, define

Dₖ(N) = Σ1≤n≤N n−2(1 − 1/n)k,

R(s,K,N) = Σk<K cₖ(s)Dₖ(N).

Lean checks the exact interchange of these finite sums. Each rectangle is a finite Dirichlet sum with every power evaluated to the same binomial degree.

Two errors, both bounded

Work on 1 + 1/(q+1) ≤ s ≤ m+2, with q > 0. Put J = m+1 and B = (m+3)J. The finite estimates are:

QuantityChecked bound
Moment(k+1)Dₖ(N) ≤ 2
Additional binomial degrees|R(s,K+L,N) − R(s,K,N)| ≤ 2(q+1)|cK(s)|, for K ≥ J
Additional Dirichlet terms|R(s,K,N+L) − R(s,K,N)| ≤ KB/N, for N > 0
Coefficient decay|cJ·2ʲ(s)| ≤ B((2q+2)/(2q+3))j

These estimates prove that the cutoff searches terminate. Intersecting the successively widened approximation boxes gives nested, valid output boxes. Explicit bounds on the finite polynomials’ variation then connect the construction to arbitrary represented real inputs through the existing adaptive function-application algorithm.

The convergence theorem controls the finite Dirichlet sums themselves: for any positive rational ε, sufficiently many terms and sufficiently fine stages place every point in the finite-sum and zeta output boxes within ε.

The current boundary

This is a reference construction, with coarse bounds and no claim of numerical efficiency near 1. Powers are constructed by the convergent binomial series. A separate proof equating that computation to exp(−s log n), parameter derivatives, Euler products, and analytic continuation remain open. The differential equation above is a formal coefficient theorem, not an analytic derivative theorem.

The construction uses the existing rational interval foundation. It adds no completed-real type, Mathlib dependency, or new axiom. The published audit records inherited foundational dependencies, including existing native-decision certificates. Identifying Apéry’s rational approximants with ζ(3) remains a separate task.

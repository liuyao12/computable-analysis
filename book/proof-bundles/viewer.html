How the line counts work

LOC counts nonblank physical Lean source lines after nested comments are removed. A bundle uses the recorded declaration spans when their endpoints are known; otherwise its badge explicitly says “file LOC” and counts the whole named file. File counts include other declarations in that file. Selecting a bundle shows every counted span and source hash.

Route totals take the union of source lines, so shared or overlapping spans are counted once. They cover the sources assigned to these bundles, not the full transitive import closure or a minimal kernel proof. Pending or unmeasured code is never scored as zero. These counts describe source size; the linked theorem audits establish proof status.

The short bars compare node counts within the selected view on a linear scale. A Mathlib source comparison can have different domains, hypotheses and number representations; it is not automatically a formal translation to our computable foundation.

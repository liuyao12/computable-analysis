\chapter{The FTC Bridge: Effective Calculus}\label{ch:effective-calculus}

This chapter supplies finite certificates consumed by the FTC contract of
Chapter~\ref{ch:integrals}.  It is not a second integral theory and does not
assert that an arbitrary classical continuous function is integrable.

\begin{verbatim}
circle/arctan -> rectangle integral -> finite derivative certificate
              -> endpoint overlap -> power series / exp / ODE instance
\end{verbatim}

\section{Certificate interface}

A special function exposes a stable rational evaluator.  Its proof supplies a
cell range, a derivative or secant bound, a mesh/evaluation schedule, and a
shrinking endpoint error.  Domain proofs are safety data, not part of the
computation.

\begin{verbatim}
primitive F, derivative box D, partition P
    -> bound D on every cell
    -> telescope F(x_(k+1))-F(x_k)
    -> endpoint box for F(b)-F(a)
\end{verbatim}

\section{Regression ladder}

Affine functions close in one exact rectangle.  Monomials test the
derivative-bound and curvature schedules:
\[
 \int_0^1x^2=1/3,\quad \int_0^1x^3=1/4,\quad
 \int_0^1x^4=1/5,\quad \int_0^1x^5=1/6.
\]
Each equality is an overlap of a finite integral evaluator and a rational
endpoint evaluator, not an appeal to a general polynomial integration rule.

give finite derivative bounds.  The implementation records those bounds on
each cell; it never quantifies over an unattained limit point.

\section{A product-rule instance}

The first non-polynomial product calculation is deliberately concrete:
\[
 F(x)=x\arctan(x),\qquad F'(x)=\arctan(x)+\frac{x}{1+x^2}.
\]
Two finite derivative-bound stages stabilize the rectangle evaluator and
identify its unit integral with \(\arctan(1)\).  This is a certified
integration-by-parts-shaped computation, not a library-wide product rule.

\begin{verbatim}
finite boxes for F' -> bounded sum -> F(1)-F(0) = arctan(1)
\end{verbatim}

\section{Trigonometric transport frontier}

The tangent-chart square integral has the quarter-turn value \(\pi/4\).
The intended \(\sin(\pi x)^2\) integral includes the reciprocal-\(\pi\)
Jacobian and is therefore a different normalized raw computation.  Its first
finite overlaps are checked.  The remaining theorem is an all-depth geometric
transport from equal-dyadic nested-radical sample boxes to tangent witnesses.

\begin{verbatim}
dyadic sine boxes --geometric overlap--> tangent witness boxes
                                         -> normalized square integral
\end{verbatim}

\section{Admission rule}

For a new calculus theorem, first build the computation. Then add only the
certificate actually needed:

\begin{verbatim}
raw evaluator -> finite range/derivative estimate -> stage schedule
              -> validity -> overlap with primitive/value computation
\end{verbatim}

The result can join the project's representation chain once one equivalence
edge to an existing raw is proved.  There is no requirement for pairwise
equivalence of every implementation, and no fallback to standard real-number
completeness.

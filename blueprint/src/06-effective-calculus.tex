\chapter{The FTC Bridge: Effective Calculus}\label{ch:effective-calculus}

The scoped Lean entry point for this chapter is
\texttt{ComputableAnalysis.EffectiveCalculusFoundation}.  It collects the
finite secant, derivative-bound, curvature, stabilization, inverse-search,
and L'Hôpital contracts used to certify an explicit evaluator.

This chapter is the proof layer for the FTC contract stated in
Chapter~\ref{ch:integrals}.  It supplies the finite certificates that a
particular evaluator must provide; it is not a second integral theory and
does not define a competing integral.  In the printed book it sits directly
between Integrals and Power Series.  The resulting dependency is:

\begin{verbatim}
circle/arctan -> integral + FTC contract -> FTC bridge: how a function earns it
                                           -> power series -> exp/log -> ODEs
\end{verbatim}

Special-function evaluators should expose a stable computation
\((x,n)\mapsto [a,b]\). Domain proofs remain available for safety, but they
are not part of the algorithm. The proof-relevant function interface adapts
such evaluators without changing the interval semantics. Regularity is stated
directly for the stable evaluator and transported once to the public API.
The exact rational constant, affine evaluator, and the nonlinear square and
cube evaluators on \([0,1]\) are checked instances of this interface; a special
function adds only its finite range and overlap lemmas.
The square and cube instances also carry finite dyadic integral certificates,
so the pointwise modulus is already connected to an actual computable area.

Coverage is by computational pattern, not by a catalogue of familiar names:
one certified representative is formalized for each new evaluator or proof
mechanism.  Rational scalar multiples, sign changes, routine compositions,
and piecewise variants reuse those certificates; a broken function such as
\(|x|\) is assembled from its finitely many interval pieces.  The remaining
detail belongs in Lean, where each new instance must expose its own domain and
stage schedule.

The same foundation also has a genuinely nonconstant Lipschitz--Darboux
route.  For the identity function, midpoint refinement gives nested rational
boxes of width \(2/2^n\); this is the model for integrating functions whose
values are not captured by one exact rectangle.  It is deliberately kept
separate from the affine FTC evaluator so that later special functions can
reuse the rectangle construction without first acquiring a symbolic
primitive.  The complete example identifies the resulting raw integral:
\(\int_0^1 x\,dx=1/2\).

\section{A normalized trigonometric bridge}

The tangent chart is a useful representative computation, but it is not yet
the original variable.  Its square integral has the quarter-turn value
\(\pi/4\).  Returning to \(\sin(\pi x)^2\) contributes the Jacobian
\(1/\pi\), so the target is represented by the product
\[
  (1/\pi)\,(\pi/4)=1/4.
\]
This is a finite interval identity between raw computations: the reciprocal
\(\pi\) evaluator and the rational-circle quarter-turn evaluator overlap at
every stage after multiplication.  The remaining sine-square theorem is
therefore a representation-transport certificate, not a new real-number
existence argument.

The search step is already complete at the finite level.  Given an overlap of
the rational-circle sine image with a positive-width nested-radical box, a
finite rational grid search returns a tangent witness; its soundness theorem
then transports the sample box.  What remains is the geometric induction that
supplies those overlaps for every dyadic cell.  A failed finite search remains
visible rather than being treated as an oracle.

\section{Continuity as a finite certificate}

The public interval-function layer supports same-chart addition.  This is the
first algebraic closure needed before proving derivative and FTC closure
rules: evaluator boxes add stage by stage, while every analytic property is
still supplied by its own finite certificate.

Continuity is not a predicate on an ambient completed function space.  A
function exposes either a pointwise modulus or an interval image algorithm:

\begin{verbatim}
requested output width -> input-width budget -> rational image box
                                           -> contains every point value
\end{verbatim}

The interval form is stronger for integration because it gives one box for an
entire cell.  It implies the rational epsilon--delta form constructively:

For addition, the finite-difference algebra is explicit:

\begin{verbatim}
(F+G)(x+h)-(F+G)(x)
  = (F(x+h)-F(x)) + (G(x+h)-G(x))
\end{verbatim}

Interval quotients obey the same identity.  If two quotient boxes are near
their derivative boxes at an internal stage, their sum is near the summed
derivative box at the requested stage after paying the doubled error budget.
This is the constructive replacement for silently invoking a derivative
closure theorem over completed real-valued functions.

Scalar multiplication is sign-complete at the same level.  A rational factor
uses an explicit budget \(|r|\,\varepsilon_{\mathrm{inner}}\leq
\varepsilon_{\mathrm{out}}\); negative factors are reduced to a nonnegative
factor followed by interval negation.  Thus finite linear combinations do not
depend on an implicit ordered-real scalar operation.

The certificate-level chain rule carries the same finite bookkeeping into the
effective derivative interface.  A positive affine slope transports the outer
step, while `hbudget` pays for the factor (m) multiplying the outer error:


\begin{verbatim}
h <= inner(eps) -> m*h <= outer radius
qabs(m) * inner(eps) <= eps -> composed derivative error <= eps
\end{verbatim}

Negative slopes require a separate two-sided or orientation-reversing
certificate; the forward-only contract does not hide that obligation.

The same finite factorization works for a general inner rational computation.
For (g(x+h)-g(x)\ne0), the composite quotient is the product of the outer
quotient at the inner increment and the inner quotient:

\begin{verbatim}
(f(g(x+h))-f(g(x)))/h
  = (f(g(x+h))-f(g(x)))/(g(x+h)-g(x))
      * (g(x+h)-g(x))/h

weighted outer error + weighted inner error <= eps
    -> effective derivative of f o g
\end{verbatim}

The constructor exposes positivity of the inner increment, both radius
transports, and the finite weighted-error budget as hypotheses.  This is the
general exact-rational chain-rule interface; interval-valued composition is a
separate future layer because its boxes need additional domain and nesting
certificates.

The registry is maintained as a spanning tree, not as a table of every
pairwise comparison.  To add a new evaluator, prove validity and one edge to

\begin{verbatim}

rewriting theorems stated at the abstract function level.

The curvature route is exposed as a finite method rather than as a classical
second-derivative theorem.  A cell carries monotone derivative data; endpoint
secants then furnish the derivative bracket used by the FTC certificate.

At the raw-representation level, a secant needs only two endpoint validity
certificates and a positive rational separation.  Convexity is used later for
ordering secants, not for proving that the secant algorithm itself is valid.

The square is the representative concrete curvature example.  Its rational
secant is exactly (x+y), so three ordered rational inputs immediately give
(operatorname{sec}(x,y)leqoperatorname{sec}(y,z)).  This is the complete
finite proof of convexity needed by the example; no second derivative,
supremum, or completed real number is introduced.  Other polynomial powers
reuse the same finite-factorization pattern only when an application actually
needs them.

\begin{verbatim}
monotone derivative on cell -> endpoint secants -> derivative interval
                            -> local endpoint bound -> effective FTC
\end{verbatim}

\section{Secants before completeness}
\label{thm:finite-quadrature-mean-value}

Historically, the mean-value relation became a way to expose the order
structure behind calculus. Here it is first stated as a finite bracket.
\begin{verbatim}
endpoint increment -> derivative bounds -> rational witness interval
\end{verbatim}
Monotone derivatives and convex functions give the cleanest first cases.
For a convex function, the secant over a cell lies between the neighboring
secants.  Thus a finite mesh supplies both the lower and upper derivative
boxes; refining the mesh is the effective replacement for invoking a least
upper bound.

The first reusable convex certificate is already checked for rational-input
functions.  If (l<u<x<y<v<r), the two outer secants bracket the interior
secant, and the bracket is packaged for direct consumption by a finite FTC or

\section{Finite L'Hôpital}
\label{thm:finite-lhopital-interface}

Cancel a common factor, expose the finite remainder, and bound it rationally;
no attained limit is required.
The resulting theorem is a precision statement: after cancellation, the
quotient interval lies within the target interval at a computably chosen
stage.  The usual limit notation is an optional presentation of this family
of finite witnesses, not a primitive of the foundation.

The reusable certificate is small:

\begin{verbatim}

\section{Application recipe}

Every new calculus theorem should expose the following finite chain before
stating its limiting-looking conclusion:

\begin{verbatim}
domain chart -> raw evaluator -> interval regularity
            -> requested-stage transport (if adaptive)
            -> cell derivative or range certificate
            -> finite partition sum -> shrinking endpoint box
            -> raw equivalence / abstract theorem
\end{verbatim}

The stopping rule is equally important. A Lipschitz or interval-regularity
proof certifies the local evaluator; it does not by itself certify an
integral. A derivative bound, curvature certificate, or finite piecewise
assembly must supply the endpoint comparison consumed by the effective FTC.
If two implementations use different schedules, add one overlap edge at the
raw level. If a function is split into finitely many pieces, prove one
representative cell and telescope the finite list; do not duplicate a global
theorem for each syntactic variant.

This is the practical boundary of the alternative foundation: all analytic
content is either a finite enclosure, a shrinking schedule, or an explicit
equivalence edge. Classical completeness is not a hidden default when one of
those inputs is absent.

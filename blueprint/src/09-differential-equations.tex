\chapter{Linear Differential Equations}\label{ch:differential-equations}

Approximate a linear ODE by finite matrix words and a certified factorial tail.

\section{Construction}
\label{thm:finite-cramer-interface}
\label{thm:finite-cayley-hamilton-boundary}

\begin{verbatim}
initial state -> finite matrix words -> tail bound -> enclosure
\end{verbatim}
Cramer's rule handles finite linear solves. Cayley--Hamilton supplies a
recurrence when an annihilating polynomial is available.

\section{Evolution and uniqueness}

Mesh transitions give a finite variation-of-constants construction and a
finite uniqueness certificate.
\begin{verbatim}
mesh -> local transitions -> compatible prefixes -> overlap
\end{verbatim}

\section{Special cases}

For rotations, matrix words split into cosine and sine prefixes.
\label{thm:linear-ode-elementary-function-agreement}

\section{Finite complex paths}

\begin{verbatim}
path -> segment increments -> finite sum -> endpoint certificate
\end{verbatim}
Polygonal closed paths therefore give finite zero-displacement identities for
the constant and polynomial differentials covered here.

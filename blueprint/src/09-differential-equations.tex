\chapter{Differential Equations}\label{ch:differential-equations}

An ODE is admitted through a finite evolution algorithm, not by an existence
theorem over an unspecified completed function space.

\begin{verbatim}
local evaluator + derivative/residual box + step budget
       -> finite evolution boxes -> nesting and tail certificate
\end{verbatim}

\section{Local solution certificates}

The first provider is the centered exponential on \([-1,1]\).  A common
Taylor prefix and rational factorial tail give boxes for the value and its
derivative; the effective FTC transports the local derivative certificate to
the endpoint relation.

\[
  y'=y,\qquad y(0)=1,qquad y(x)=\exp(x)
\]
is therefore a chain of finite certificates, rather than an appeal to a
globally defined real exponential.

\begin{verbatim}
Taylor prefix -> factorial tail -> derivative box
              -> effective FTC -> local initial-value certificate
\end{verbatim}

\section{Finite evolution}

For a linear system, the Peano--Baker construction is finite ordered-word
algebra.  At a fixed stage it enumerates the permitted time-ordered products,
forms rational matrix boxes, and proves a remainder budget.  The order of
matrix factors is part of the computation, not informal notation.

\begin{verbatim}
ordered index words -> finite matrix products -> rational sum
                    -> tail majorant -> evolution raw
\end{verbatim}

\section{What remains general}

The completed part is a usable local template: analytic evaluator, explicit
tail, derivative/residual certificate, finite step composition, and overlap
with any alternate evaluator.  A general vector analytic provider still needs
its own tail and stability certificate.  The blueprint intentionally records
that as work rather than replacing it with a classical all-ODE theorem.

\section{Complex paths}

Complex path integration follows the same rule.  A path is a rational
parameter evaluator with complex boxes; a finite partition produces a finite
sum.  Its algebra is already useful for contour-shaped calculations, while
general holomorphic integration is not assumed.

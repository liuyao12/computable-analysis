\chapter{Exponential and Logarithm}\label{ch:exponential-logarithm}

The scoped Lean entry point for this chapter is
\texttt{ComputableAnalysis.ExponentialLogarithmFoundation}.  It collects
Taylor-prefix and tail certificates, rotation coordinates, and gap-aware
inverse data.  Routine variants are transported from these representative
computations.

Power series and the effective FTC now provide the two basic tools: evaluate
finite prefixes with tails, and transport derivative identities to endpoint
identities. Exponential, logarithm, and their trigonometric connections are
built from these tools.

This chapter is organized by computational pattern, not by a catalogue of
names. One representative is formalized for each new algorithm; scalar
multiples, sign changes, and routine compositions are transported from it.
Piecewise functions are finite assemblies of their interval pieces, so a
function such as $|x|$ does not require a second general integration theory.

\section{Exponential}

\begin{verbatim}
Taylor prefix -> remainder bound -> rational enclosure -> refine
\end{verbatim}

The exponential is introduced by its rational Taylor evaluator.  Its algebra
and differential laws are finite prefix identities plus transported tail
bounds; no completed real line is needed.
\begin{verbatim}
expPrefix(x,N) -> expTailBound(x,N) -> expInterval(x,eps)
                 -> exp(x+y), derivative, inverse certificates
\end{verbatim}
The certified power-series evaluator is exposed independently of domain
proofs, with geometric tail metadata. The reciprocal kernel is likewise
exposed on the positive interval \([1,2]\); its interval image is
\([1/I_{\rm hi},1/I_{\rm lo}]\).

The evaluator contract is uniform across rational inputs:

\begin{verbatim}
input x -> choose N from the tail budget
        -> sum x^k/k! for k <= N
        -> enclose the signed remainder
        -> return a rational interval
\end{verbatim}

The tail argument is itself finite.  After choosing the first omitted degree,
every later finite Taylor prefix is enclosed by the same rational factorial
majorant.  This is the project’s potential-infinity replacement for asserting
that a sequence has converged in a completed real line.

\section{Logarithm and Euler identity}

Reciprocal bounds and finite composition provide the computable core. The
completed logarithm bridge is recorded only when its representation is made
explicit.

On a positive rational interval, logarithm can be represented by a monotone
inverse-exponential search.  The concrete branch \(\log 2\) is already
formalized in two equivalent ways: an alternating reciprocal series and a
dyadic integral of \(1/x\) on \([1,2]\).  Their equivalence is proved by
finite rational box comparisons and is used in the arctangent/\(\pi\) bridge.
The remaining transport is specifically the identification of this branch
with the canonical inverse of the exponential evaluator.
\begin{verbatim}
positive target -> monotone inverse search -> log interval
log/exp overlap -> log identities and Euler rotation law
\end{verbatim}

The inverse search follows the same pattern as the tangent search in the
integral chapter: a rational source cell is bisected, the forward exponential
image is enclosed, and a finite separation certificate selects the next cell.
Thus logarithm requires no global inverse-function theorem; each positive
interval branch carries its own source, range, and separation data.

The separation certificate is explicit for the unit exponential: positive
finite Taylor coefficients give the linear lower bound
\[
  y-x \le \operatorname{expCenter}(y)-\operatorname{expCenter}(x),
\]
and a gap-dependent factorial stage makes the endpoint boxes disjoint.

This closes the analytic data for a branch-local gap-aware inverse search. The
older fixed-gap `InvertibleFunctionOnInterval` contract remains available for
algorithms whose separation modulus is uniform; the exponential branch now
uses the more faithful `GapAwareInvertibleFunctionOnInterval` contract.
The exact target-one regression search returns the rational preimage (0),
which is the computable branch statement (log 1=0).
More generally, every rational source point in the branch supplies a
forward-computed target and an exact inverse regression: the target is the
warm-stage computation of (exp r), and the returned source box is (r,r).
This validates the inverse contract on a family of targets while leaving the
decision-driven bisection algorithm as the next construction.
As an intermediate target-driven test, the rational target (3/2) is searched
against a finite exponential center by exact midpoint decisions.  The
resulting certificate exposes both the preserved endpoint bracket and the
literal width (2^{-k}); it is the finite kernel to be lifted to the
gap-aware, stage-indexed target algorithm.
The forward-overlap theorem makes the bridge explicit: the interval-valued
exponential cell range at the same finite center stage still overlaps (3/2).
On the actual warm exponential branch, the first three midpoint decisions for
the target (3/2) are also checked explicitly, producing the brackets
([0,1/2]), ([1/4,1/2]), and ([3/8,1/2]).
The same trace is generated by the fixed-precision proof-carrying iterator.
When every midpoint decision is certified strict, the generic theorem gives
the exact geometric width law (initial width)/(2^n).  The analytic content is
therefore isolated in the finite separation certificates.
For the warm exponential target (3/2), those certificates are now supplied
for stages 0, 1, and 2, yielding width 1/8 by the generic theorem.

The inverse layer is deliberately branch-local.  An invertible computation
must carry its source interval, monotonicity orientation, separation schedule,
and certified target range; an inverse evaluator then returns a rational source
box whose forward image overlaps the target box.  This is the constructive
replacement for saying that a continuous monotone function has an inverse.
The midpoint kernel is conservative: it discards a half only when its whole
computed image box lies strictly below or above the target box; an ambiguous
overlap retains the parent interval.  Any claimed progress theorem must
therefore provide the missing precision/separation certificate explicitly.

\begin{verbatim}
log integral branch -> inverse branch -> exponential branch

therefore compared through explicit raw equivalences. The chain can transport
an identity such as the real Euler value without identifying the underlying
algorithms definitionally. This is the same spanning-tree principle used for
realRaw and complexRaw computations elsewhere in the project.

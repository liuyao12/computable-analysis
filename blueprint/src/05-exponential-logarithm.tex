\chapter{Exponential and Logarithm}\label{ch:exponential-logarithm}

Exponential and logarithm are special computations assembled from the series,
FTC, and inverse-search interfaces.  They are not imported as functions on
standard real numbers.

\begin{verbatim}
finite Taylor prefix + factorial tail -> exponential evaluator
positive monotone branch + bisection  -> logarithm evaluator
explicit overlap edges                -> common abstract functions
\end{verbatim}

The scoped Lean entry point is
\texttt{ComputableAnalysis.ExponentialLogarithmFoundation}.

\section{Exponential}

For rational \(x\), the evaluator chooses a finite degree, computes
\(\sum_{k\le N}x^k/k!\), and attaches a signed factorial-tail interval.
Every later finite prefix lies in the same enclosure.

\section{Complex rotation}

The same factorial prefix at an imaginary input gives rational-complex sine
and cosine coordinates.  Their derivative laws are finite prefix identities
plus the same tail transport:

\[
  S'=C,\qquad C'=-S,\qquad S(0)=0,\qquad C(0)=1.
\]

\section{Logarithm by inverse search}

On a positive branch, logarithm may be computed by bisection against the
exponential evaluator.  A midpoint is discarded only when its whole
finite image box is strictly below or above the target.

\begin{verbatim}
positive target -> source bracket -> finite exp image boxes
                -> strict midpoint decision -> nested source bracket
\end{verbatim}

The key analytic input is gap-aware separation: the evaluator stage is chosen
from the actual rational gap between trial inputs.  Positive Taylor
coefficients give the lower separation bound on the unit branch.

\section{Logarithm by integral}

The second logarithm representation integrates the reciprocal kernel on a
positive rational interval.  On \([1,2]\), its derivative enclosure is a
finite secant estimate with denominators separated from zero.

\section{Representation chain and Euler connection}

The intended chain is

\begin{verbatim}
integral logarithm <-> inverse exponential <-> power-series exponential
                                      |
                                      +-> complex rotation
\end{verbatim}

Each arrow is a pointwise overlap theorem between computations.  A spanning
tree of these arrows is enough; pairwise comparison of every implementation
is unnecessary.

The integral-defined branch already supports the square-pullback and
arctangent-strip identities used in the \(\pi\) comparison.

\section{Interface}

\begin{verbatim}
explicit evaluator -> finite regularity/derivative/inverse certificate
                   -> valid raw computation -> one equivalence edge
\end{verbatim}

New exponential or logarithmic algorithms should connect through this chain.
Routine shifts, signs, scalings, and local restrictions are transported from
the existing representatives.

\chapter{Algebraic Root Certificates and the FTA Boundary}\label{ch:algebra-fta}

This chapter is included only because root isolation is an infinite
refinement process used by special functions and ODEs.  Routine finite
polynomial algebra is reused from Lean.

The scoped entry point is
\texttt{ComputableAnalysis.AlgebraicFoundation}.

\section{Finite root search}
\label{thm:finite-box-polynomial-soundness}

A candidate complex box is evaluated by rational interval arithmetic.  A box
whose polynomial image excludes zero is discarded; the others are subdivided.

\begin{verbatim}
rational polynomial + initial box -> interval evaluation
                                  -> reject or subdivide
                                  -> shrinking retained boxes
\end{verbatim}

The reusable subdivision theorem covers the parent, preserves any supplied
root, and gives the exact dyadic width and height after each finite depth.

\lean{ComputableAnalysis.FiniteFTASubdivision.dyadicChildren_cover}
\lean{ComputableAnalysis.FiniteFTASubdivision.root_mem_survivingSubdivide}
\lean{ComputableAnalysis.FiniteFTASubdivision.survivingSubdivide_nestedIn_parent}
\lean{ComputableAnalysis.FiniteFTASubdivision.survivingSubdivide_width_height_exact}
\leanok

The quadratic example checks both sides of the contract: two supplied roots
survive, while a rational neighborhood of zero is excluded.

\lean{ComputableAnalysis.finiteFTAQuadratic_upper_root}
\lean{ComputableAnalysis.finiteFTAQuadratic_lower_root}
\lean{ComputableAnalysis.finiteFTAZeroNeighborhood_is_root_free}

These are soundness theorems for finite search.  A complete FTA
formalization still needs an effective existence argument ensuring that the
retained boxes isolate all roots without importing a completed algebraically
closed field.

\section{Algebraic represented values}

An exact rational or rational-complex point has a nonzero linear annihilator.
More general algebraic computations pair a shrinking complex box with an
explicit polynomial witness.  Arithmetic on their boxes is computable;
annihilators for sums and products remain explicit elimination obligations.

\section{Boundary}

The present chapter provides:

\begin{verbatim}
finite exclusion + supplied-root preservation + finite deflation
\end{verbatim}

The Wiedijk FTA target requires one further constructive theorem:

\begin{verbatim}
polynomial data -> finite stage and retained boxes
                -> all roots represented, isolated, and exhausted
\end{verbatim}

Until that provider is proved, the project does not describe finite
subdivision soundness as a completed Fundamental Theorem of Algebra.

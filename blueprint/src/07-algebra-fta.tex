\chapter{Algebraic Root Certificates and the FTA Boundary}\label{ch:algebra-fta}

An algebraic value is a rational box together with a polynomial-image
certificate. Isolation and deflation are finite; completed-number
identification is a bridge.

\section{Isolation and deflation}
\label{thm:finite-box-polynomial-soundness}
\label{thm:finite-deflation-soundness}
\label{thm:rational-cubic-roots}
\label{thm:rational-quartic-roots}
\label{thm:finite-factor-remainder-interface}
\label{thm:finite-descartes-sign-interface}

\begin{verbatim}
box -> interval polynomial evaluation -> discard or subdivide
    -> optionally deflate a supplied exact factor
\end{verbatim}
This replaces radical formulas by finite search. Cubic and quartic examples
illustrate isolation, factor/remainder certificates, and Descartes-style sign
counts.

\section{Boundary}

The supplied-root quintic certificate is a boundary result: it peels known
factors, but is not a general quintic solver.

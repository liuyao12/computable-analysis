\chapter{The Fundamental Theorem of Algebra}\label{ch:algebra-fta}

An algebraic value is represented by a rational box and a certificate about
the polynomial image.

\section{Isolation and deflation}

\begin{verbatim}
box -> interval Horner evaluation -> discard or subdivide
    -> optionally deflate a supplied exact factor
\end{verbatim}
Rational-root search is finite and conditional on its candidate list;
isolation supplies the computable substitute for a radical formula.

\section{Boundary}

There is no general degree-five radical formula. Global termination and a
completed algebraic closure require separate bridges; the finite certificates
remain the computational core.

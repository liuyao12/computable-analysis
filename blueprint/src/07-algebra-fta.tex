\chapter{The Fundamental Theorem of Algebra}\label{ch:algebra-fta}

A root is a rational box whose polynomial image meets zero.

\section{Isolation and deflation}

\begin{verbatim}
boxes -> interval Horner evaluation
      -> discard boxes missing zero
      -> subdivide survivors / deflate supplied factors
\end{verbatim}
Quadratic, cubic, quartic, Descartes, and deflation certificates are included.
Global termination requires a modulus.
\begin{verbatim}
remove zero coefficients
count sign changes
check count + 1 <= surviving length
\end{verbatim}

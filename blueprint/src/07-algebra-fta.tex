\chapter{The Fundamental Theorem of Algebra}\label{ch:algebra-fta}

A root is a rational box whose polynomial image can meet zero.

The finite soundness rule is explicit: if a box's Horner image misses zero,
discard it; if a supplied root is known, synthetic division records the factor.

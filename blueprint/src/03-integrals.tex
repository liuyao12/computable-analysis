\chapter{Integrals}
\label{ch:integrals}

An integral here is a named rational-box algorithm plus its validity proof.
There is no ambient completed-real integral and no table of antiderivatives.
The GIFs show the computations; the linked Lean declarations contain their
finite certificates.

\section{From \texorpdfstring{\code{arctan.geom}}{arctan.geom} to definite integrals}

\begin{remark}[The geometric prototype]
\label{rem:arctan-geom-general-integral}
\code{arctan.geom} encloses area by rational cells.  Replace its circle
density by a particular function, prove the cell boxes shrink, and obtain an
integral.  This is a per-function construction, not a universal operator.
\end{remark}

\begin{definition}[Monotone-function integral stage]
\label{def:increasing-integral-stage}
\lean{ComputableAnalysis.NondecreasingOnInterval}
\lean{ComputableAnalysis.IntervalRegularOn}
\lean{ComputableAnalysis.Integral.nondecreasingDarbouxRange}
\lean{ComputableAnalysis.Integral.nondecreasingDarbouxRange_width_nonneg}
\lean{ComputableAnalysis.Integral.nondecreasingDarbouxStage}
\lean{ComputableAnalysis.Integral.nondecreasingDarbouxDyadicStage}
\uses{rem:arctan-geom-general-integral,def:interval-regular}
For a nondecreasing \(F\) on \([a,b]\), use opposite endpoints of the dyadic
partition and retain the function-value boxes:
\begin{verbatim}
def increasing_integral_stage(F, a, b, n):
    P = uniform_partition(a, b, 2**n)
    q = evaluation_stage(F, n)
    lower = sum((P[i+1]-P[i]) * F(P[i], q).lo for i in range(len(P)-1))
    upper = sum((P[i+1]-P[i]) * F(P[i+1], q).hi for i in range(len(P)-1))
    return [lower, upper]
\end{verbatim}
\noindent
For a decreasing piece, interchange the two endpoints in this display.  Thus
the evaluator always consumes rational intervals, even when a particular
function happens to have exact rational endpoint values.
\begin{figure}[!htbp]
\centering
\monotoneIntegralStageAnimation
\caption{Exact rational lower and upper stages for
\(\displaystyle 1/(1+t^2)\); its endpoint boxes are singletons.}
\label{fig:monotone-integral-stage}
\end{figure}
Monotonicity orders each cell; interval regularity and a function-specific
width estimate prove that the stage sequence is a \code{RealRaw}.
\end{definition}

\begin{definition}[Piecewise-monotone stage computation]
\label{def:piecewise-monotone-stage}
\lean{ComputableAnalysis.Integral.PiecewiseMonotoneConstructionFor}
\lean{ComputableAnalysis.Integral.piecewiseMonotoneIntegralFor}
\uses{def:increasing-integral-stage}
The animation uses the normalized sinc example
\[
 s(t)=\frac{\sin(\pi t)}{\pi t},\qquad s(0)=1,\qquad 0\le t\le2
\]
decreasing and then increasing.  Its first nonzero turn \(\tau\) satisfies
\(\tan(\pi\tau)=\pi\tau\), and is represented only by shrinking rational
brackets \([\ell_n,r_n]\).  This is only the smallest picture of the general
finite-piece algorithm:
\begin{verbatim}
def piecewise_monotone_stage(F, monotone_pieces, turn_brackets, n):
    tails = [monotone_stage(F, P.left(n), P.right(n), n, P.direction)
             for P in monotone_pieces]
    gaps  = [(T.right(n)-T.left(n)) * T.value_range
             for T in turn_brackets]
    return sum(tails) + sum(gaps)
\end{verbatim}

certificate that bisects the tangent residual; the existing

\end{definition}

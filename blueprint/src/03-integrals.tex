\chapter{Integrals}\label{ch:integrals}

An integral is a program returning nested rational bounds.  Lebesgue measure
and completed-real integration are outside scope.

\section{Rectangle algorithm}

Classify each cell as increasing, decreasing, or containing a finitely
bracketed turn.
\begin{verbatim}
mesh := equal dyadic subdivision
pieces := certify cell behavior
return sum(lower rectangles), sum(upper rectangles)
\end{verbatim}

\chapter{Integrals}\label{ch:integrals}

An integral is a program returning nested rational bounds.  No Lebesgue
measure or completed-real integral is required.

\section{Rectangle algorithm}

Use endpoint rectangles on monotone pieces.  For finitely many turns, first
certify the pieces.
\begin{verbatim}
mesh := equal dyadic subdivision
pieces := certify up, down, or turning behavior
return sum of lower and upper rectangles
\end{verbatim}

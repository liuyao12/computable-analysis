\chapter{Integrals}\label{ch:integrals}

An integral is a program returning nested rational bounds. Lebesgue measure is
outside scope; the central object is a certified rectangle computation.

The blueprint writes sine only as \(\sin(\pi x)\).  A normalized quarter-turn
parameter may occur inside the circle algorithm as an implementation detail.

\section{Rectangle algorithm}

For each cell, certify monotonicity or isolate finitely many turns.
\begin{verbatim}
mesh -> cell classification -> lower/upper rectangles -> overlap
\end{verbatim}
This gives the computable mean-value/area principle for the functions covered
by the certificates.

\section{Finite identities}
\label{thm:finite-green-rectangle}
\label{def:integration-by-parts-certificate}
\label{thm:integration-by-parts-certificate}
\label{cor:arctangent-logarithm-pi-route}

\begin{verbatim}
finite boundary sum -> algebraic identity -> endpoint difference
                                      -> certified error budget
\end{verbatim}
Green's rectangle identity, substitution, telescoping, integration by parts,
and polynomial FTC are instances of this finite pattern.

\section{Tails and products}

Compactify the domain, bound the tail, and combine finite bounds. Multiple
integrals are iterated finite enclosures; Gaussian and $n$-ball formulas are
the main examples.
\begin{verbatim}
finite boxes -> product bounds -> tail certificate -> nested enclosure
\end{verbatim}

\section{Interface}

\begin{verbatim}
intervals -> monotone pieces -> finite identities -> overlap
\end{verbatim}

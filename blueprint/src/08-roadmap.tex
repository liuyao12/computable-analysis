\chapter{Formalization Roadmap}

The blueprint is a map, not a second proof.  Figures show computations,
pseudocode states invariants, and Lean carries the finite estimates.

\section{Admission rule}

Add a result only when it contributes a new interval algorithm, represented
domain, convergence estimate, integral/derivative certificate, or
equivalence edge.  Routine finite algebra and combinatorics are dependencies.
Scalar multiples, sign changes, degree variants, and finitely piecewise
functions are transported from one representative theorem.

The canonical Lean entry point is
\texttt{ComputableAnalysis.CalculusFoundation}.  Its import chain uses Lean's
rational ordered arithmetic and project modules, not standard real numbers,
measure theory, topology, or a completion construction.

\section{Dependency order}

\begin{verbatim}
foundations -> circle/trigonometry -> finite integrals -> effective FTC
            -> series/Fourier -> exponential/logarithm -> linear ODEs
\end{verbatim}

Algebraic root certificates form a parallel branch.  They enter the calculus
route only when a special function or complex application needs them.

\section{Canonical FTC boundary}

The effective derivative-bound certificate now produces a valid integral,
not merely a same-stage overlap:

\begin{verbatim}
finite cell bounds
  -> bounded sums with shrinking width
  -> overlap with valid endpoint computation
  -> prefix stabilization
  -> valid integral equivalent to endpoint difference
\end{verbatim}

Successive finite sums may use unrelated partitions.  The proof derives
shrinking width and then supplies nestedness; it does not assume the native
candidate was already a valid \texttt{realRaw}.  The squared finite sine
prefix is the first nonlinear regression of this exact route.

\section{Main representation frontier}

For the equal-dyadic integral of \(\sin(\pi x)^2\), two pairwise geometric
certificates remain:

\begin{verbatim}
public dyadic squares
  <-> nested-radical squares
  <-> normalized tangent-square anchor
  <-> 1/4
\end{verbatim}

Overlap is not transitive for arbitrary interval boxes.  The chain
stabilizer widens by the vanishing middle width and then intersects prefixes
against the valid anchor.  Therefore no three-way same-stage witness is
required.

The remaining work is the uniform rational-circle certificate for every
dyadic sample and the nested-radical-to-normalized-anchor witness.  Fixed
depth checks are regression tests, not substitutes for these all-stage
theorems.

\chapter{Formalization Roadmap}

\section{Admission rule}

Keep a result when it yields a rational certificate, a shrinking `realRaw`
algorithm, a valid `real`, or an overlap statement.  Reuse routine finite
combinatorics unless it controls refinement, tails, or error.

\section{Order}

\begin{verbatim}
intervals -> circle/rectangles -> tails/series/pi
          -> secants/MVT/FTC -> algebraic isolation -> linear ODEs
\end{verbatim}

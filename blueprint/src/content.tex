\chapter*{Preface}
\addcontentsline{toc}{chapter}{Preface}

This project develops calculus from explicit finite computations.  A raw real
is an algorithm
\[
  n\longmapsto [a_n,b_n],\qquad a_n,b_n\in\Q,
\]
together with proofs that the intervals are ordered, nested, and shrink to
arbitrary rational precision.  Independent algorithms are identified by
finite overlap certificates.  The abstract real retains useful algorithms
and a maintained tree of such equivalences; a raw algorithm stores none of
them.

The calculus route is
\begin{verbatim}
rational intervals -> circle/trigonometry -> integral -> effective FTC
                   -> series/Fourier -> exponential/logarithm -> linear ODEs
\end{verbatim}
Every function is an explicit computation on its natural represented domain.
The project adds one representative for each genuinely new computational
pattern and transports routine scalar, sign, polynomial, and finite-piece
variants.  It does not assert that every continuous function is integrable or
import completeness of the standard real numbers.

The integral chapter introduces rectangle algorithms and the endpoint-area
question.  The effective-calculus chapter supplies the derivative bounds,
width budgets, and stabilization theorem that answer it.  Native finite sums
may be chosen independently at successive stages; the canonical FTC theorem
proves shrinking and stabilizes them against the primitive endpoint
computation rather than assuming they were already nested.

\section*{Wiedijk's List of 100 Theorem Formalization Challenge}
\noindent\href{https://www.cs.ru.nl/\%7Efreek/100/index.html}
{Freek Wiedijk's original list of 100 theorems.}

The project tracks only the sixteen entries whose content belongs to
represented numbers, infinite processes, calculus, or function theory.
Routine finite algebra, combinatorics, and elementary coordinate geometry are
reused from Lean when needed.  A linked entry states the project's computable
target; it does not silently claim a stronger classical theorem.
